# Attribution

This project is an independent, reduced implementation inspired by architectural ideas in
[Fosowl/agenticSeek](https://github.com/Fosowl/agenticSeek), including specialized agents,
provider abstraction, constrained browser automation, and planner-style task execution.

No AgenticSeek source files are included in this repository. AgenticSeek is licensed under GPL-3.0.
This project intentionally keeps its own implementation small and focused on QA automation for MySANA.
